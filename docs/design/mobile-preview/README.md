# Varin 手机交互设计稿

在仓库根目录安装项目依赖后运行以下命令，在浏览器打开 [本地预览](http://127.0.0.1:5192/)。

```sh
bun x vite --config docs/design/mobile-preview/vite.config.mjs
```

从「合作演示」里的文件可以进入全文、选中一段并引用到原对话。左上角返回会话列表，从这里可以进入群聊、处理「访谈笔记」里待回复的问题，或切到工作台看父子任务和文件改动。桌面预览顶部可以切换手机、平板和明暗主题。

可直接打开[单聊](http://127.0.0.1:5192/?room=outline)或[群聊](http://127.0.0.1:5192/?room=group)。点单聊上方的角色打开 Bot 面板，点群聊的成员合影查看成员、协作和日程。在成员名单点 @ 会回到原来的草稿，可以接着输入。用量和 MCP 的快捷入口在工作台对话右上。

列表左上是 Varin／工作台模式菜单。「助手」旁可以创建 Bot，顶栏文件夹按钮可以新建分组，Bot 行末可以调整归属。会话菜单可以创建单聊或群聊。

[工作台会话列表](http://127.0.0.1:5192/?view=workbench)可以切换「最近」和「分类」。分类里可以建立项目和分组，在其中新建会话，或把已有会话移动进去。列表样式可以切换树状和平铺；最近视图按派发关系收纳子任务。

主题、图标、头像资源、按钮、编辑器和消息菜单来自产品代码。会话及附件使用示例数据，发送和编辑草稿只作用于当前浏览器标签页。麦克风只展示布局。预览使用独立端口，无需启动 Varin 服务。
